# EPGCustom 5차 공급원 실사 기록 (2026-10-14)

## 조사 범위와 원칙

Oracle2 개발 환경에서 Synology FF MyEPG / KR1 XMLTV와 현재 Shyni 활성 채널 정보를 읽기 전용으로 비교했다. **Synology FF·MyEPG·ALive·ff_iproxy2·Shyni·Live Proxy의 운영 소스·DB·설정·재생 주소는 수정하지 않았다.**

별개의 방송인 EBS2(EBS 2TV)와 EBS플러스2, CJ ONSTYLE(본채널)과 CJ ONSTYLE PLUS/+, SPOTV Prime과 Prime+는 자동으로 합치지 않는다. 각 채널이 사용 가능한 편성표를 실제로 보유한 경우에만 연결한다.

## 추가 공급원 조사

| 후보 | 확인 결과 | 이번 버전 적용 |
|---|---|---|
| EPGShare01 한국 KR1 XMLTV | 정상 응답, 한국 방송 편성 데이터 존재. v0.3.0부터 사용하던 외부 공급원 | **기존 공급원 유지** |
| iptv-org GitHub Pages 한국 Wavve TVING XMLTV | `https://iptv-org.github.io/epg/guides/ko/wavve.com.xml`, `.../ko/tving.com.xml` 직접 조회 시 각각 HTTP 404 | 미추가 |
| EBS 공식 EBS2 편성표 | 웹페이지에 실제 일정은 확인됐으나 `https://www.ebs.co.kr/robots.txt`에 `User-agent: * / Disallow: /` 명시 | **자동 스크래핑 미구현** |
| Wavve 기존 공개 가이드 API(EBS2 E07) | GitHub의 채널 목록에 EBS2 E07이 있으나 HTTPS 연결 인증서 오류로 유효한 EPG 획득 실패 | 미추가 |
| TVING 전용 FAST 채널 | 정확하게 해당 개별 FAST 채널을 식별할 수 있고 현재 날짜의 편성을 제공하는 재사용 가능한 XMLTV 소스는 확보하지 못함 | 미추가 |

**주의:** 외부 사이트의 웹페이지가 사람에게 보인다는 사실만으로 자동 수집·재배포 권한이 확인되는 것은 아니다. EBS robots 제한을 존중하며, 별도의 공식 제공 API나 사용 허가를 확인하기 전에는 EBS2 스크래퍼를 추가하지 않는다. 외부 EPGShare01의 이용·재배포 조건은 사용자별 운영 목적에 맞게 따로 검토한다.

## MyEPG + KR1 데이터로 검증된 추가 이름 매핑

2026-10-14 실제 KR1에 유효 편성 항목이 존재하며, 별개 방송이 아닌 이름 표기로 판단되는 4건만 기본 별칭에 추가했다.

| Shyni 대상 채널 ID | KR1 표시 이름 | KR1 원본 ID | 별칭 의미 |
|---|---|---|---|
| `SK스토아` | `SK stoa` | `SK.stoa.kr` | 같은 브랜드의 한글/영문 표기 |
| `공영홈쇼핑` | `공영쇼핑` | `공영쇼핑.kr` | 회사명/방송 브랜드 표기 |
| `CJ ONSTYLE` | `CJ 온스타일` | `CJ.온스타일.kr` | 영어/한글 브랜드 표기, PLUS와 구분 |
| `현대홈쇼핑+샵` | `현대홈쇼핑+Shop` | `현대홈쇼핑+Shop.kr` | +샵/+Shop 번역 표기, 일반 현대홈쇼핑과 구분 |

기존 설정 JSON에 같은 채널 ID가 있으면 사용자 별칭이 우선한다. `{"SK스토아":[]}`처럼 빈 배열을 입력하면 자동 별칭을 개별 비활성화할 수 있다.

## 독립 메모리 생성 비교 (해당 시점 기준)

- 원본 MyEPG+KR1 연결: **101채널** (MyEPG 52, KR1 49)
- v0.5.0 별칭 적용: **105채널** (MyEPG 52, KR1 53)
- 새 연결된 채널: SK스토아, 공영홈쇼핑, CJ ONSTYLE, 현대홈쇼핑+샵 **4개**
- 기존에 연결된 채널 소실: **0개**
- 시험 당시 Shyni 활성 채널 ID는 232개. 16:44의 기존 FF 보고서에는 233개였으므로 채널 수는 고정된 상수가 아닌 조회 시점의 M3U 값으로 사용한다.
- 신규 연결 상태·출력 XMLTV의 고유 ID/편성 참조·그룹별 연결 수 합계의 일치 여부를 검증했다.
- 여전히 EBS2·SPOTV Golf&Health 및 Wavve/티빙 FAST 계열은 검증된 독립 공급원이 필요한 상태다.

## 다음 공급원 채택 기준

1. 현재 날짜에 유효한 원본 편성 및 프로그램 시간대를 실제 샘플로 검증한다.
2. 채널 ID와 프로그램 성격이 대상 라이브 채널과 같은지 확인한다. 비슷한 이름만으로 다른 방송을 매핑하지 않는다.
3. 공급 사이트의 이용 조건, robots 정책, 재배포·자동수집 허용 여부를 확인한다.
4. 부가 공급원 장애 시 기존 XMLTV 보존과 MyEPG 우선 정책을 유지한다.
5. 개발 저장소의 격리 테스트 통과 후 FF 운영 업데이트는 별도 단계로 진행한다.
